# JailBreaker English Patch

An English translation patch for the Japanese PSX release of **JailBreaker**.
You need your own Japanese game bin/cue set as no game files or copyrighted work is distributed here,

This was translated with the assistance of OpenAI Codex. The text was reviewed and edited by a human where necessary.

The translation methodology sourced as much information about the game laid across the internet and read through the text of the game to establish profiles for the setting and the characters to establish their tone and word choices when applicable. The game itself had fairly easily translatable text, so only a few liberties were taken.
Specifically the main characters name is presented and written in Japanese as Shlla, however the english voice overs in the FMV refer to her as Shura. So for consistency with the official established english in-game I used Shura.

The FMV videos are already voiced in english. As such, I did not feel the need to overwrite the japanese subtitles with english for this release. This may be something I do in a future release, as the english can be a bit quiet and difficult to hear at some points.

## Patching manually

Apply each xdelta patch to its matching original bin file.
